# Blog

Многопользовательская блог-платформа с микросервисной архитектурой на базе FastAPI, MongoDB и Docker Compose.

## Архитектура системы

Проект состоит из двух взаимодействующих сервисов и базы данных:

1. **`blog_service`** (основной сервис):
   * Управление пользователями (регистрация, аутентификация).
   * Публикация, редактирование, удаление и постраничная выдача статей с фильтрацией по тегам и поиском по заголовку.
   * Система комментариев внутри постов с возможностью редактирования и удаления авторами.

2. **`reporting_service`** (сервис аналитики):
   * Получает публикации основного сервиса по HTTP в формате JSON.
   * Агрегирует и вычисляет общую статистику: суммарное количество постов и комментариев на платформе.

3. **`mongo`**:
   * Документоориентированная СУБД MongoDB для хранения аккаунтов пользователей и постов с вложенными комментариями.

```text
.

│   ├── models.py              # Pydantic-схемы валидации данных (User, Post, Comment)

│
├── stats_service/
│   ├── config.py              # URL основного сервиса (BLOG_SERVICE_URL)
```


## Спецификация API

### Сервис контента (`blog_service`: порт 8000)

* `POST /auth/register` — регистрация нового аккаунта.
* `POST /auth/login` — аутентификация и проверка пароля.
* `GET /api/posts` — получение списка публикаций.
* `GET /api/posts/{post_id}` — получение поста и списка комментариев по ID поста.
* `POST /api/posts` — создание новой публикации.
* `PUT /api/posts/{post_id}` — редактирование статьи автором.
* `DELETE /api/posts/{post_id}` — удаление статьи автором.
* `POST /api/posts/{post_id}/comments` — добавление комментария к посту.
* `PUT /api/posts/{post_id}/comments/{comment_id}` — редактирование текста комментария автором.
* `DELETE /api/posts/{post_id}/comments/{comment_id}` — удаление комментария автором.

* `GET /api/stats` — выгрузка отчета в формате:
